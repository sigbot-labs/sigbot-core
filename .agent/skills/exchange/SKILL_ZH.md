您正在开发交易所客户端模块。该模块提供用于与各种交易所（CEX、DEX、股票、预测）交互的 SDK。

**架构与职责**：
- 提供订单管理器用于执行订单的交易所客户端 SDK
- 支持多种交易所类型：CEX（中心化交易所）、DEX（去中心化交易所）、股票交易所、预测市场
- 处理特定于交易所的 API 交互和数据规范化

**主要职责**：
1. **交易所客户端 SDK**：
   - 为所有交易所类型提供统一接口
   - 实现特定于交易所的客户端（Binance、Uniswap 等）
   - 支持订单放置、取消、修改
   - 支持持仓和余额查询

2. **市场数据访问**：
   - 获取市场数据（klines、订单簿、交易）
   - 支持实时数据流（WebSocket）
   - 规范化来自不同交易所的数据

3. **订单执行**：
   - 通过交易所 API 放置订单
   - 取消挂单
   - 修改现有订单
   - 查询订单状态

4. **账户管理**：
   - 查询账户余额
   - 查询持仓
   - 查询交易历史
   - 支持多币种账户

**编码指南**：

1. **交易所抽象**：
   - 使用基于 trait 的设计（`IExchangeClient` 或 `ExchangeProvider`）
   - 为所有交易所类型实现 trait（CEX、DEX、股票、预测）
   - 将特定于交易所的数据结构规范化为通用类型（`sigbot-types`）
   - 支持用于交易所创建的工厂模式

2. **交易所类型**：
   - **CEX（中心化）**：REST API + WebSocket（Binance 等）
   - **DEX（去中心化）**：区块链交互（Uniswap 等）
   - **股票**：股票交易所 API
   - **预测**：预测市场 API

3. **API 集成**：
   - 处理特定于交易所的认证（API 密钥、签名）
   - 为认证端点实现请求签名
   - 支持 REST 和 WebSocket 连接
   - 处理特定于交易所的速率限制

4. **错误处理**：
   - 将特定于交易所的错误映射到 `ExchangeError` 枚举
   - 使用指数退避处理速率限制
   - 处理网络失败和超时
   - 记录带有完整上下文的交易所 API 错误（交易所、端点、错误）
   - 区分临时错误和永久错误

5. **速率限制**：
   - 遵守特定于交易所的速率限制
   - 实现每个交易所的速率限制跟踪
   - 在超过速率限制时排队请求
   - 支持速率限制恢复

6. **异步操作**：
   - 所有交易所 API 调用必须是异步的
   - 为 HTTP 客户端使用连接池（reqwest）
   - 实现外部调用的超时处理
   - 支持带适当速率限制的并发 API 调用

7. **数据规范化**：
   - 对共享类型使用 `sigbot-types`（Order、Trade、Kline、Balance、Position）
   - 将时间戳规范化为 UTC
   - 处理不同的交易所符号格式（规范化为通用格式）
   - 将特定于交易所的订单类型转换为通用类型
   - 规范化价格和数量格式（小数处理）

8. **订单执行**：
   - 支持不同的订单类型（市价、限价、止损等）
   - 处理订单状态更新
   - 支持部分成交
   - 跟踪订单执行历史

9. **安全**：
   - 永远不要记录 API 密钥或密钥
   - 为凭据使用安全存储
   - 实现适当的请求签名
   - 验证交易所响应

10. **性能**：
    - 优化 API 调用（在可能时批量）
    - 使用高效的序列化/反序列化
    - 缓存交易所元数据（符号、费用）
    - 监控 API 调用延迟

11. **测试**：
    - 在单元测试中模拟交易所 API
    - 测试错误场景（网络失败、速率限制、无效响应）
    - 验证数据规范化正确性
    - 测试订单执行流程
    - 测试并发 API 调用
    - 使用测试夹具进行一致的测试

12. **配置**：
    - 支持每个交易所的配置
    - 配置 API 端点和凭据
    - 配置速率限制和超时
    - 支持环境特定设置
