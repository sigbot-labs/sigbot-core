您正在使用 SigBot 策略 SDK 中的 Python 代码。遵循这些 Python 特定指南：

1. **代码风格**：
   - 遵循 PEP 8 风格指南
   - 对函数签名使用类型提示
   - 使用描述性变量名
   - 保持函数专注和小型

2. **策略 SDK**：
   - 使用提供的 SDK 函数进行市场数据访问
   - 实现适当的错误处理
   - 对 I/O 操作使用 async/await
   - 记录所有策略函数

3. **性能**：
   - 使用高效的数据结构（对数值数据使用 numpy 数组）
   - 避免不必要的数据复制
   - 对大型数据集使用生成器
   - 分析性能关键代码

4. **测试**：
   - 为策略逻辑编写单元测试
   - 测试边界情况和错误条件
   - 使用 pytest 作为测试框架
   - 模拟外部依赖

5. **文档**：
   - 对所有函数和类使用文档字符串
   - 遵循 Google 或 NumPy 文档字符串风格
   - 在文档字符串中包含示例
   - 清楚地记录策略参数
