您正在开发回测服务器模块 (SigbotBacktestServer)。该微服务提供历史数据回测能力。

**架构与职责**：
- **回测服务器**： 
  - 从 TimescaleDB 加载历史 kline/tick/市场/新闻数据
  - 将历史数据发布到 EMQX (ISigbotMessagerClient) 以模拟实时市场数据
  - 策略运行器订阅此模拟市场数据并执行策略逻辑
  - 提供模拟交易所订单 API（接收来自订单管理器的交易信号）
  - 定期检查持仓以进行模拟清算
  - 更新 s_bt_ledger、s_bt_balance、s_bt_position 表
  - 为钱包管理器同步提供模拟交易所持仓查询 API

**主要职责**：
1. **历史数据加载**：
   - 从 TimescaleDB 加载历史数据（klines、ticks、市场数据、新闻）
   - 支持时间范围查询
   - 处理数据间隙和缺失时段
   - 优化大数据集的查询

2. **数据发布**：
   - 以模拟实时速度将历史数据发布到 EMQX
   - 保持适当的时间进度
   - 支持不同的播放速度
   - 处理数据发布错误

3. **模拟交易所 API**：
   - 实现模拟订单放置 API
   - 模拟带延迟和滑点的订单执行
   - 处理订单取消和修改
   - 返回真实的交易所响应

4. **持仓管理**：
   - 在 s_bt_position 表中跟踪持仓
   - 检查持仓的清算条件
   - 执行模拟清算
   - 更新持仓状态

5. **账本与余额管理**：
   - 使用模拟交易更新 s_bt_ledger
   - 使用余额变化更新 s_bt_balance
   - 维护交易历史
   - 支持余额对账

6. **模拟交易所持仓 API**：
   - 为钱包管理器提供查询持仓的 API
   - 返回匹配交易所格式的持仓数据
   - 支持定期同步

**编码指南**：

1. **历史数据管理**：
   - 高效地从 TimescaleDB 加载和缓存历史数据
   - 支持多个数据源（Klines、Trades、News）
   - 优雅地处理数据间隙和缺失时段
   - 优化数据查询性能（使用索引、时间分区）
   - 支持大数据集的流式数据加载

2. **时间模拟**：
   - 实现适当的时间进度（模拟实时）
   - 支持可配置的播放速度
   - 在所有数据流中保持时间一致性
   - 处理时间跳跃和暂停

3. **模拟交易所实现**：
   - 模拟真实的市场条件
   - 处理订单执行延迟和滑点
   - 支持不同的订单类型（市价、限价、止损）
   - 模拟部分成交和订单拒绝
   - 返回真实的交易所错误响应

4. **订单执行模拟**：
   - 计算真实的执行价格（带滑点）
   - 处理订单匹配逻辑
   - 支持不同的市场条件（正常、波动、低流动性）
   - 模拟交易所延迟

5. **持仓与清算**：
   - 准确跟踪持仓
   - 定期检查清算条件
   - 在满足条件时执行清算
   - 原子性地更新持仓

6. **数据库更新**：
   - 在事务中更新 s_bt_ledger、s_bt_balance、s_bt_position
   - 确保数据一致性
   - 支持并发更新
   - 为查询使用适当的索引

7. **指标计算**：
   - 计算标准交易指标（夏普比率、回撤、胜率等）
   - 支持自定义指标定义
   - 高效存储指标
   - 提供指标可视化数据
   - 在回测期间实时计算指标

8. **性能**：
   - 优化大型历史数据集
   - 使用流式处理数据
   - 在可能时实现并行回测执行
   - 缓存中间结果
   - 监控内存使用

9. **错误处理**：
   - 优雅地处理数据加载错误
   - 处理模拟交易所 API 错误
   - 记录带有完整上下文的错误
   - 支持错误恢复机制

10. **测试**：
    - 使用各种历史数据场景进行测试
    - 验证指标计算
    - 测试回测准确性和可重现性
    - 测试模拟交易所 API 行为
    - 测试持仓清算逻辑
    - 使用大数据集验证性能
    - 测试并发回测执行

11. **配置**：
    - 支持可配置的播放速度
    - 配置滑点和执行延迟
    - 配置清算参数
    - 支持回测特定设置
