您正在开发策略运行器模块 (`SigbotStrategyRunner`)。该微服务基于市场数据执行交易策略。

**架构与职责**：
- **策略运行器**：订阅来自 EMQX (ISigbotMessagerClient) 的市场/新闻数据作为输入，执行策略逻辑以生成交易信号，并将交易信号发布到 EMQX

**主要职责**：
1. **市场数据订阅**：
   - 订阅来自 EMQX 的市场数据主题（TOPIC_MARKET_STREAMS）
   - 解析市场数据消息（klines、ticks、新闻）
   - 处理实时数据流

2. **策略执行**：
   - 执行用户定义的策略（Rust、Python 等）
   - 在隔离/沙盒环境中运行策略
   - 处理策略错误而不使系统崩溃
   - 基于策略逻辑生成交易信号

3. **信号发布**：
   - 将交易信号（`SigbotTradeSignal`）发布到 EMQX (TOPIC_TRADING_SIGNALS)
   - 包含信号元数据（strategy_id、signal_id、tenant_id）
   - 确保信号传递可靠性

4. **策略 SDK**：
   - 为策略开发者提供 SDK
   - 支持多种编程语言
   - 公开市场数据访问 API
   - 提供订单管理接口

**编码指南**：

1. **消息驱动架构**：
   - 异步处理市场数据
   - 优雅地处理数据反序列化错误
   - 支持并发策略执行
   - 在需要时保持每个符号的数据顺序

2. **策略执行引擎**：
   - 在沙盒环境中隔离策略执行
   - 实现策略超时机制
   - 优雅地处理策略 panic/错误
   - 记录策略执行指标（延迟、错误）
   - 支持热重载策略

3. **SDK 设计**：
   - 为策略开发者提供清晰、文档完善的 API
   - 支持多种语言（Rust、通过 SDK 的 Python）
   - 仔细版本化 SDK API（向后兼容性）
   - 提供市场数据访问函数
   - 公开技术指标和实用工具

4. **数据处理**：
   - 高效处理高频市场数据
   - 使用高效的数据结构（避免不必要的克隆）
   - 缓存频繁访问的数据
   - 支持数据聚合（OHLCV、指标）

5. **信号生成**：
   - 在发布前验证信号
   - 在信号中包含所有必需的元数据
   - 支持不同的信号类型（买入、卖出、修改、取消）
   - 处理信号生成错误

6. **AI 集成**（用于 sigbot-researcher）：
   - 使用 LangChain 进行 LLM 交互
   - 在执行前验证生成的策略代码
   - 实现代码审查和安全检查
   - 在适当时缓存生成的策略

7. **性能**：
   - 优化低延迟策略执行
   - 对市场数据使用高效的数据结构
   - 实现策略结果缓存
   - 定期分析策略执行
   - 支持并行策略执行

8. **错误处理**：
   - 处理策略错误而不使系统崩溃
   - 记录带有完整上下文的错误（strategy_id、data、error）
   - 对失败的策略实现熔断器
   - 支持错误恢复机制

9. **测试**：
   - 使用各种市场数据输入测试策略执行
   - 验证策略隔离和沙盒
   - 测试信号生成逻辑
   - 测试并发策略执行
   - 测试错误场景（策略 panic、超时）
   - 验证生成的代码安全性（对于 AI 生成的策略）

10. **配置**：
    - 支持每个策略的配置
    - 允许启用/禁用特定策略
    - 配置执行超时和资源限制
    - 支持策略特定参数
