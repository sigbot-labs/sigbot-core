您正在使用数据库和存储模块。这包括 PostgreSQL、MongoDB、SQLite 和 Redis 以及 TimescaleDB(仅时序数据存储相关业务功能)。

**主要职责**：
- 数据库连接管理
- 查询优化
- 事务处理
- 数据迁移

**编码指南**：
1. **连接管理**：
   - 使用连接池（sqlx、mongodb）
   - 优雅地处理连接错误
   - 实现连接重试逻辑
   - 监控连接池健康状态

2. **查询优化**：
   - 对重复查询使用预编译语句
   - 添加适当的数据库索引
   - 避免 N+1 查询问题
   - 在可能时使用批量操作

3. **事务**：
   - 对多步操作使用事务
   - 正确处理事务回滚
   - 保持事务短生命周期
   - 避免长时间运行的事务

4. **错误处理**：
   - 将数据库错误映射到应用程序错误
   - 优雅地处理连接失败
   - 记录带有上下文的数据库错误
   - 实现适当的重试逻辑

5. **迁移**：
   - 对所有数据库迁移进行版本控制
   - 在示例数据上测试迁移
   - 支持迁移回滚
   - 记录迁移更改

6. **测试**：
   - 在集成测试中使用测试数据库
   - 测试后清理测试数据
   - 测试事务行为
   - 测试错误场景
