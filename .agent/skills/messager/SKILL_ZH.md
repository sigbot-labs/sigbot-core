您正在开发消息器模块。该模块为 EMQX (MQTT) 和本地消息传递提供消息代理抽象。

**架构与职责**：
- 提供 `ISigbotMessagerClient` trait 用于消息代理抽象
- 支持 MQTT (EMQX) 和本地消息代理
- 被所有微服务用于发布/订阅消息
- 实现跨系统的事件驱动架构

**主要职责**：
1. **消息代理抽象**：
   - 抽象消息代理操作（发布、订阅）
   - 支持多个代理实现（MQTT、Local）
   - 为所有微服务提供统一接口

2. **MQTT 集成**：
   - 连接到 EMQX MQTT 代理
   - 处理 MQTT 连接生命周期
   - 支持 QoS 级别（0、1、2）
   - 处理重连逻辑

3. **本地消息传递**：
   - 为测试提供内存消息代理
   - 支持本地发布/订阅操作
   - 对开发和测试有用

4. **主题管理**：
   - 支持主题通配符（单级 +、多级 #）
   - 处理主题订阅和取消订阅
   - 支持多租户主题

**编码指南**：

1. **Trait 设计**：
   - 使用 `ISigbotMessagerClient` trait 进行抽象
   - 保持 trait 方法异步
   - 支持 Send + Sync 边界以进行并发使用
   - 返回 Result 类型以进行错误处理

2. **工厂模式**：
   - 对代理创建使用工厂模式
   - 支持运行时代理选择
   - 动态注册代理实现
   - 支持单例实例

3. **MQTT 实现**：
   - 使用 rumqttc 或 paho-mqtt crate
   - 处理连接生命周期（init、close）
   - 适当支持 QoS 级别
   - 实现带指数退避的重连
   - 处理 MQTT 特定错误

4. **消息处理**：
   - 支持消息序列化（JSON）
   - 处理消息反序列化错误
   - 支持二进制和文本消息
   - 提供具有适当签名的消息处理器

5. **订阅管理**：
   - 跟踪活动订阅
   - 支持每个主题的多个处理器
   - 优雅地处理订阅失败
   - 支持通配符订阅

6. **错误处理**：
   - 将特定于代理的错误映射到通用错误类型
   - 优雅地处理连接失败
   - 实现临时失败的重试逻辑
   - 记录带有完整上下文的错误

7. **性能**：
   - 对所有操作使用 async/await
   - 支持并发发布/订阅
   - 在适用时使用连接池
   - 监控消息吞吐量

8. **测试**：
   - 在测试中模拟消息代理
   - 测试发布/订阅操作
   - 测试错误场景（连接失败）
   - 测试重连逻辑
   - 测试通配符订阅

9. **配置**：
   - 支持特定于代理的配置
   - 配置连接参数（主机、端口、凭据）
   - 配置 QoS 和其他 MQTT 设置
   - 支持基于环境的配置
