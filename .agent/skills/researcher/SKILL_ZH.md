您正在开发 SigBot 研究员模块。这是一个基于 sigbot-core 构建的更高级别的 AI 驱动策略研究子项目。

**架构与职责**：
- **SigBot 研究员**：AI 驱动的自主策略研究系统（虚拟策略开发者）
- **SigbotResearchManager**：扫描 s_research_case 表以查找待处理案例并启动研究任务的微服务
- **多智能体工作流**：编排器执行多智能体工作流：
  1. 数据源智能体：使用智能体工具从 sigbot-core API 或第三方 API 获取数据（支持 a2a+x402 协议用于自动支付）
  2. Alpha 生成智能体：生成策略代码
  3. 回测智能体：执行回测并生成性能报告
  4. 金融审计智能体：审查回测报告（检查夏普比率、最大回撤、胜率阈值），审计策略代码安全性（极端市场条件），生成全面的安全评估报告
  5. 投资组合管理智能体：全面评估回测性能报告和策略逻辑/资本安全评估报告，最终批准决定

**主要职责**：
1. **研究案例管理**：
   - 提供研究案例列表 API
   - 提供创建新研究案例 API
   - 跟踪研究案例状态（待处理、运行中、已完成、失败）
   - 存储研究案例配置和参数

2. **研究任务执行**：
   - 为待处理案例启动研究任务
   - 使用分布式锁防止并发任务执行
   - 跟踪任务执行历史
   - 存储多智能体工作流进度

3. **多智能体编排**：
   - 在工作流中协调多个智能体
   - 在智能体之间传递数据
   - 处理智能体失败和重试
   - 跟踪智能体执行进度

4. **智能体实现**：
   - 数据源智能体：使用工具获取市场数据
   - Alpha 生成智能体：使用 LLM 生成策略代码
   - 回测智能体：通过 sigbot-core API 执行回测
   - 金融审计智能体：分析回测结果和代码安全性
   - 投资组合管理智能体：做出最终批准决定

5. **部署集成**：
   - 提供部署按钮/API 以将批准的策略部署到 sigbot-core
   - 传输策略代码和配置
   - 部署后更新研究案例状态

**编码指南**：

1. **研究案例管理**：
   - 在 PostgreSQL（s_research_case 表）中存储研究案例
   - 通过 API 支持 CRUD 操作
   - 跟踪案例状态和历史
   - 支持案例过滤和搜索

2. **分布式锁定**：
   - 对任务扫描使用分布式锁（Redis、PostgreSQL 咨询锁）
   - 防止多个实例处理同一案例
   - 优雅地处理锁获取失败
   - 实现锁超时和续期

3. **任务执行**：
   - 异步启动研究任务
   - 跟踪任务进度和状态
   - 存储任务执行日志
   - 处理任务失败和重试

4. **智能体架构**：
   - 对智能体使用基于 trait 的设计（`IAgent`）
   - 支持可插拔的智能体实现
   - 为外部 API 访问提供智能体工具
   - 处理智能体通信和数据传递

5. **编排器设计**：
   - 实现工作流状态机
   - 处理工作流转换
   - 支持基于智能体结果的条件分支
   - 处理工作流失败和回滚

6. **LLM 集成**：
   - 使用 LangChain 进行 LLM 交互
   - 为 LLM 智能体提供智能体工具
   - 处理 LLM API 错误和重试
   - 在适当时缓存 LLM 响应

7. **数据源智能体**：
   - 使用智能体工具调用 sigbot-core API
   - 支持第三方市场数据 API
   - 支持 a2a+x402 协议用于自动支付
   - 处理 API 认证和错误

8. **Alpha 生成智能体**：
   - 使用 LLM 生成策略代码
   - 验证生成的代码语法
   - 确保代码遵循 SDK 模式
   - 存储生成的代码以供审查

9. **回测智能体**：
   - 调用 sigbot-core 回测 API
   - 监控回测进度
   - 检索回测结果
   - 解析性能指标

10. **金融审计智能体**：
    - 分析回测性能指标
    - 检查阈值（夏普比率、最大回撤、胜率）
    - 审计策略代码的安全问题
    - 测试极端市场条件
    - 生成全面的安全报告

11. **投资组合管理智能体**：
    - 评估回测性能报告
    - 评估策略安全评估
    - 做出最终批准/拒绝决定
    - 提供决策理由

12. **错误处理**：
    - 优雅地处理智能体失败
    - 支持工作流重试机制
    - 记录所有智能体操作和决策
    - 存储错误详情以供调试

13. **测试**：
    - 在测试中模拟智能体实现
    - 测试工作流编排逻辑
    - 测试分布式锁定行为
    - 测试智能体通信
    - 测试错误场景

14. **配置**：
    - 支持每个智能体的配置
    - 配置 LLM 模型和参数
    - 配置批准阈值
    - 支持环境特定设置
