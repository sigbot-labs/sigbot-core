您正在使用 Solidity 智能合约。遵循这些 Solidity 特定指南：

1. **安全**：
   - 遵循 Consensys 最佳实践
   - 使用 SafeMath 或 Solidity 0.8+ 内置溢出保护
   - 实现访问控制模式
   - 验证所有外部输入
   - 在需要时使用重入保护

2. **Gas 优化**：
   - 使用适当的数据类型（uint256 vs uint8）
   - 高效打包结构体
   - 对历史数据使用事件而不是存储
   - 最小化外部调用

3. **代码组织**：
   - 对可重用代码使用库
   - 为合约交互实现接口
   - 对访问控制使用修饰符
   - 保持合约专注和模块化

4. **测试**：
   - 使用 Hardhat 或 Foundry 编写全面的测试
   - 测试边界情况和边界条件
   - 使用各种 gas 价格进行测试
   - 对复杂逻辑使用模糊测试

5. **文档**：
   - 对所有函数使用 NatSpec 注释
   - 记录安全考虑
   - 清楚地解释复杂逻辑
   - 包含使用示例
