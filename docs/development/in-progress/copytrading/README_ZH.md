# Copy Trading 研究草稿

[文档索引](../../../index_ZH.md)

**状态：** 进行中；非生产研究原型。

本目录用于存放 Sigbot 上线前期实盘测试阶段的临时研究脚本和筛选记录，主要用于观察 Binance Copy Trading 带单项目。

本研究只提供候选筛选依据，不构成自动交易决策或生产运行时依赖。结论稳定后，
可复用规则应合并到所属正式规范；过程记录完成或失效后归档。

核心筛选原则：

- 胜率不能太低，也不能太高。胜率过高往往意味着马丁、抗单或长期不止损；在加密市场这种极高波动环境里，很容易一夜回到解放前，活下来是必备技能。
- 夏普比和最大回撤是综合衡量盈利能力质量的关键指标。优先选择风险调整后收益高、回撤受控的项目，而不是只看夸张 ROI。
- ROI 需要放在风险指标之后看。高收益但回撤控制差的项目，不适合作为早期实盘测试对象。
